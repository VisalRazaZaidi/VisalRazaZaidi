### 🎯 [AI Job Tracker](https://ai-job-tracker-jegm.vercel.app/)

A personal job CRM that brings applications, recruiters, resumes, and role-specific AI analysis into one workspace.

- Tracks applications through a searchable pipeline with immutable submission snapshots
- Analyzes job descriptions, scores resume fit, identifies skill gaps, and generates tailored resume versions
- Includes recruiter follow-ups, PDF import/export, insights, and user-scoped data security
- **Stack:** Next.js, React, TypeScript, PostgreSQL, Prisma, Clerk, Google Gemini, TanStack Query, Zod, Vitest
- **[Live app](https://ai-job-tracker-jegm.vercel.app/)** · **[Source code](https://github.com/VisalRazaZaidi/Ai-Job-Tracker)**

### 💰 [Worth PK](https://worth-pk.vercel.app/)

An AI-assisted resume analyzer that helps early-career developers understand their position in Pakistan's technology market.

- Extracts skills and experience from uploaded PDF resumes
- Estimates role-based salaries across Karachi, Lahore, and Islamabad
- Compares candidate skills with leading Pakistani technology companies and suggests practical next steps
- **Stack:** Next.js, React, Tailwind CSS, PDF.js, Gemini/OpenAI APIs
- **[Live app](https://worth-pk.vercel.app/)** · **[Source code](https://github.com/VisalRazaZaidi/Worth-PK)**
